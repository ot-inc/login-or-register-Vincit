# login-or-register-form

A modern and responsive Login and Registration Form built using HTML, CSS, and JavaScript.

The project was created as part of my software development learning journey and demonstrates front-end development concepts including from validation, DOM manipulation, responsive design, and user interface development.

## About the project

The Login or Register Form provides a clean and user-friendly authentication interface where users can either create a new account or sign in using an existing acccount.

The project focuses primarily on the front-end experience and demonstrates how authentication forms can be structured, styled, validated, and made responsive using HTML, CSS, and JavaScript.


## Features

-  User registration form
-  User login form
-  Responsive design
-  Login/register form switching
-  Mobile-friendly interface
-  Clean and modern 

## Technologies
## HTML5
Used to create the structure and form elements of the application.

## CSS

Used for:

- Form validation

- DOM manipulation
- Password visibility
- Login/Register switching
- User feedback
